Command-line tool for quickly creating dummy files.

Usage: dummy [OPTIONS] <SIZE> <UNIT> <DESTINATION>
Example: dummy 24 m ~/test

### Installation
1. Clone the repo
2. Enter the cloned repo directory
3. Install by running ``cargo install --path .``

Note that to call the installed program from anywhere, your cargo binary directory (usually ``~/.cargo/bin``) must be in your system's ``$PATH``
